Making a Debug APK : 
```
ng build
npx cap sync android
cd android
.\gradlew assembleDebug
```
Find the apk at : 
`D:\PROJECTS\Elytra-Notes\elytra-notes-app\android\app\build\outputs\apk\debug\app-debug.apk`
