### Popular AWS Services : 

1. EC2 (Elastic Compute Cloud): 
	- Provides scalable virtual servers in the cloud to run applications, websites and backend services.
2. S3  (Simple Storage Service) :
	- Object Storage service used to store and retrieve files like images, videos, backups and logs.
3. Elastic Container Registry : 
	- Managed Docker container registry for storing, managing and deploying container images.
4. Elastic Container Service : 
	- Container orchestration service to run and manage Docker containers without managing infrastructure. 
5. Elastic Kubernetes Service : 
	- Fully managed Kubernetes service to deploy, manage and scale containerized applications using Kubernetes
 6. IAM  (Identity Access Management) : 
	- Controls access to AWS resources by managing users, roles and permissions securely.
7. CloudWatch : 
	- Monitoring and logging service to track application performance, system metrics and trigger alerts.
8. CloudTrail : 
	- Tracks and logs all API activity and user actions in AWS for auditing and security.
9. Amazon DocumentDB : 
	- Managed NoSQL database service compatible with MongoDB, used for storing JSON like data.
10. Aurora and RDS :
	- Managed relational database services for running SQL databases like MySQL, PostgreSQL with scalability and automation.
11. ElasticCache : 
	- In-memory caching service (Redis/Memcached) used to improve application performance by reducing database load.
12. Simple Queue Service (SQS) :
	- Managed Message queue service used to decouple and asynchronously communicate between different components of a system
13. Simple Notification Service (SNS) : 
	- Pub/sub messaging service used to send notifications or messages to multiple subscribers (email, SMS, Lambda, etc.)
14. Simple Email Service (SES) : 
	- Cloud-based email service for sending transactional emails, notifications and marketing message at scale
