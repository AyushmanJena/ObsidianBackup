Theory for Cloud Computing



Cloud Computing Roadmap : 
Step 1 : Prerequisites 
1. Basic Computer Networking : Understanding OSI Layer, IP Addresses, DNS, HTTP/HTTPS and firewalls
2. Operating Systems : Familiarity with Linux and Windows, including basic commands
3. Programming Basics 
4. Databases : Both SQL and NoSQL databases
5. Virtualization :Basic understanding of virtualization and Virtual Machines VMs

Step 2  : Cloud Computing Fundamentals
1. Basic Cloud Computing concepts
2. Deployment models : Public, Private, Hybrid
3. Service Models : IaaS, PaaS, SaaS
4. Key Benefits : Scalaibilty, flexibility, cost effectiveness, disaster recovery
5. Popular CLoud Providers : AWS, Azure, etc.

Step 3 : Choose a Cloud Provider and Get Hands-On Experience : 
1. Start with Free Tiers
2. AWS: Free tier with services like EC2, S3, RDS
3. Azure: Free tiral with credits for services like Virtual Machines and Azure Blob Storage
4. Hands On Exercices
5. Create a virtual Machine
6. Store and retrieve files using cloud Storage
7. Setup a simple website using cloud hosted servers
8. Learn serverless computing by using Lambda (AWS) or Functions (Azure/GCP)
