### Types of Hosting Platforms : 
1. On Premises Servers 
	- Bring your own machines, connectivity, software, etc.
	- Complete control and responsibility
	- Static Capabilities
	- High capital costs for infrastructure
	- Only considered when security is a major concern
2. Dedicated Hosted Servers
	- Renting Machines, connectivity, software
	- Less control and responsibilities
	- Lower Capital costs 
	- Flexible 
	- Pay for fixed capacity, even if idle
	- Ex : Mocahost, etc.
3. Cloud Hosting Platforms
	- Shared, multi-tenant infrastructure
	- Virtualized and Dynamic
	- Scalable and Available
	- Abstracted from the infrastructure
	- Higher level services
	- Pay as you go

# Cloud Computing : 
App and infrastructure over Internet
Compute as a service : Applications over the Internet
Utility : Pay as you go for hardware and software

Three new aspects to cloud computing : 
- Virtually Infinite computing resources available on demand
- Elimination of upfront commitment by cloud users
- Ability to pay for use on short term basis

> [!NOTE]
> Cloud Computing  is a compilation of existing techniques and technologies, packaged within a new infrastructure paradigm that offers improved scalability, elasticity, business agility, faster start-up time, reduced management costs and just in time availability of resources.

Cloud is typically a large data-center


Cloud Computing examples : Google Drive, Dropbox, Streaming Services (Netflix, Spotify), etc.

Major Cloud Providers : 
1. Amazon Web Services (AWS)
2. Microsoft Azure
3. Google Cloud Platform 
4. Alibaba Cloud
5. IBM Cloud
6. Oracle Cloud
7. Salesforce, etc. 


Key Characteristics of Cloud Computing : 
- On Demand self Service
- Pay as you go pricing
- Broad Network access : Services are accessible from ay device
- Resource : Resources are shared among multiple users efficiently. Dynamically
- Scalability and Elasticity : Adjust resources as per need


### AI as a Service (AIaaS)
- It refers to cloud based platform that offer ready to use AI tools and services, enabling businesses to implement artificial intelligence without needing to build or maintain the underlying infrastructure.
- Pre-Trained Models : Ready to use AI models for tasks like language translation, image recognition, and sentiment analysis
- Ex :
	- AWS SageMaker, amazon rekognition, Amazon Polly
	- Google Cloud AI : AutoML, VIsion AI, Diagramflow
	- etc. 


# Cloud Core Architecture 
Hierarchical  
##### 1.  Region
- Geographical area  where cloud services are hosted. Ex: Asia Continent
- Contains multiple availability zones
##### 2. Availability Zone
- Physically isolated datacenter within a region
- Provides redundancy and fault tolerance within same region
##### 3. Datacenter
- A datacenter is the smallest unit, housing the physical infrastructure like servers, storage, and networking equipment.
- Multiple datacenters make up an availability zone.

### Standards and Frameworks in Cloud
Cloud Providers need to gain these certificates (not mandatory)
##### 1. ISO/IEC 27017 (Cloud Security Guidelines)
- Provides guidelines for information 
##### 2. ISO/IEC 27018 (Data Protection in Cloud)
- Focuses on protecting Personally Identifiable Information (PII) in public clouds.
##### 3. NIST SP 800-53 and NIST SP 500-291
- Security and privacy controls for federal information systems and organizations.
- Specific recommendations for cloud computing environments.
##### 4. Cloud Security Alliance (CSA) Controls Matrix
- A detailed framework of security concepts tailored for cloud environments, covering
areas like IAM, compliance, and risk management.
##### 5. General Data Protection Regulation (GDPR)
-Governs the protection of personal data in the European Union and impacts cloud data
handling practices.
##### 6. SOC 2 (System and Organization Controls)
-Evaluates cloud service providers' adherence to trust principles like security
availability, and confidentiality.
##### 7. CIS Benchmarks (Center for Internet Security)
-CIS Benchmarks are globally recognized best practices for securing IT
systems and cloud environments.
##### 8. HIPAA (Health Insurance Portability and Accountability Act)
-A U.S. regulation that ensures the security and privacy of health data. It
applies to cloud services hosting protected health information (PHI).
